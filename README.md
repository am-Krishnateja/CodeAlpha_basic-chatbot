# Rule-Based Chatbot

This is a simple rule-based chatbot built using Python.  
It responds to basic user inputs with predefined replies.

## Features
- Responds to simple inputs like "hello", "how are you", and "bye"
- Uses predefined rules (no AI or external libraries)
- Console-based interaction

## Concepts Used
- if-elif conditions
- functions
- loops
- input/output handling

## How to Run
1. Run the Python file.
2. Type messages in the console.
3. Chatbot responds based on predefined rules.
4. Type "bye" to exit.

## Example
You: hello  
Chatbot: Hi!  

You: how are you  
Chatbot: I'm fine, thanks!  

You: bye  
Chatbot: Goodbye!
